### How to Read This

Alive = scheduled today in a live scheduler (Hermes cron verified in .hermes/cron/jobs.json, or launchd agent verified via launchctl list) Dead = emitted notes exist but no scheduler references them (verified: OpenClaw crons.db empty, 0-byte, marked DEAD-20260728; jobs archived to _pre-migration-archive-2026-07-17/) The nightly KB maintenance pass (Phase 2) keeps this page current — it is the registry's designated owner
