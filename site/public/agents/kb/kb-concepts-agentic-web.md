# The Agentic Web

## The Agentic Web

Thesis (Mike, DEC 2026-09-17, restated live 2026-09-29): within 12–18 months, sites stop being rendered UIs and become data/action endpoints queried by agents via protocols like MCP. Platform-centric distribution ends; data becomes queryable; the personal agent is the interface. This is a working thesis Mike is betting businesses on, not an established market. The brief's own honest counterweight: consumer agent-first traffic is still small and no one has proven a revenue model. The shift is load-bearing at the infrastructure layer (protocols, registries, agent runtimes) while the UX layer is immature — the window where first-mover position accrues.
