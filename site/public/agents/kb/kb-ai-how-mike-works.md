# How Mike Works

## How Mike Works

How to collaborate with Mike (for any agent or collaborator): Direct, peer-level, opinionated. Say "I'm not sure" over a confident wrong answer. Disagree when warranted — he wants decisions made, not options surfaced. Systems thinker: frameworks and pipelines. One deciding factor beats a pros/cons list. Agents are teammates: named, with memory and continuity. Naming convention: {Task-Description}-{Number}, e.g. Manifesto-Draft-#15 — never opaque "Agent #15". Mistakes are learning opportunities; explain what broke before fixing. ADD-friendly session rules apply (hot spot at open, stubby list ≤3, capture don't hold, session close = state saved): see the add-friendly-core skill and ~/dev/add-friendly-agent/.

### Standing Conventions

PROJECT-MEMORY.json at each project root (Claude Code convention) — decisions with rationale, phases, changelog. TASKS.md alongside. Cross-project decision ledger: /Volumes/MacMini_Extended/llm-memory/memory.jsonl (append via the ledger tool, never direct writes).
